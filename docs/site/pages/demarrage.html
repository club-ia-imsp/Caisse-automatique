PREMIÈRE EXÉCUTION

Démarrer le prototype.

La base de données, le serveur et l’interface sont regroupés dans le dossier AutomaticCheck.

1. Préparer Python

cd AutomaticCheck
python -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
pip install -r requirements.txt

L’environnement virtuel isole Flask et pyserial des autres projets Python. Les dépendances déclarées sont Flask ≥ 2.0 et pyserial ≥ 3.0.

2. Initialiser le catalogue

python create_db.py

Cette commande crée la table produits si elle est absente, puis insère ou met à jour les produits de démonstration. Elle peut être relancée sans dupliquer un UID.

3. Lancer l’interface

python backend.py

Le serveur écoute sur le port 5000. Ouvrir http://localhost:5000 sur le PC, ou http://<IPv4-du-PC>:5000 depuis un téléphone sur le même Wi‑Fi.

Sans matériel : cliquer sur « Mode test — simuler un scan RFID ». Le parcours panier/paiement peut ainsi être validé entièrement.

Configurer le lecteur

Le port par défaut est COM4. Avant le démarrage, adapter si nécessaire :

$env:RFID_PORT = 'COM5'
$env:RFID_BAUD = '115200'
python backend.py

Consulter /api/status pour connaître les ports détectés et le statut du lecteur. Le lecteur doit envoyer une ligne texte contenant l’UID.
