PUBLICATION

Mettre la documentation en ligne.

Le site est entièrement statique : il peut être ouvert localement sans installation, puis publié gratuitement via GitHub Pages dans le dépôt de votre organisation.

Démarrer localement

La façon la plus simple est de double-cliquer sur docs/site/index.html. Tous les liens et l’image fonctionnent sans serveur.

Pour obtenir une adresse locale avec un vrai serveur web, exécuter depuis la racine du projet :

python -m http.server 8000 --directory docs/site

Ouvrir ensuite http://localhost:8000. Ce serveur sert seulement la documentation ; il ne lance pas le système RFID.

Publier dans une organisation GitHub

  1. Créer ou choisir un dépôt dans l’organisation, par exemple Organisation/AutomaticCheck.
  2. Envoyer le projet et vérifier que la branche principale s’appelle main.
  3. Dans le dépôt GitHub : Settings → Pages → Build and deployment → Source, choisir GitHub Actions.
  4. Le fichier .github/workflows/deploy-documentation.yml déjà ajouté publie automatiquement docs/site à chaque envoi sur main.
  5. Attendre la fin de l’action « Publier la documentation », puis ouvrir le lien affiché dans son résumé.

Adresse attendue

Pour un dépôt de projet AutomaticCheck appartenant à Organisation, l’adresse est généralement :

https://organisation.github.io/AutomaticCheck/
Droit requis : un propriétaire de l’organisation ou un administrateur du dépôt doit autoriser GitHub Pages et les GitHub Actions. Si le dépôt est privé, la disponibilité de Pages dépend du forfait et des règles de l’organisation.

Première mise en ligne en terminal

git init
git add .
git commit -m "Ajout de la documentation AutomaticCheck"
git branch -M main
git remote add origin https://github.com/Organisation/AutomaticCheck.git
git push -u origin main

Remplacer Organisation par le nom exact de votre organisation. Si le dépôt existe déjà localement, ne pas exécuter git init : ajouter uniquement les fichiers, commiter puis pousser.
