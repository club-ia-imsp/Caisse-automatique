API FLASK

Les routes disponibles.

Toutes les réponses sont JSON, sauf la route racine qui distribue l’interface web. Le serveur écoute par défaut sur http://localhost:5000.

GET
/
Retourne frontend/index.html.
GET
/api/cart
Retourne items, total, l’état série et le dernier scan.
GET
/api/status
Retourne le port configuré, le débit et les ports détectés.
POST
/api/add_uid
Ajoute/retire l’UID reçu dans le JSON {"uid":"338FE7F7"}. Répond 400 si absent, 404 si inconnu.
POST
/api/simulate_scan
Simule un scan ; sans UID, choisit un produit SQLite aléatoire.
POST
/api/clear
Vide le panier en mémoire.
POST
/api/pay
Refuse un panier vide, sinon retourne le montant puis vide le panier. Ce n’est pas un paiement réel.
GET
/api/products
Retourne le catalogue trié par nom.

Exemple de réponse panier

{
  "items": [{"uid":"338FE7F7","nom":"Livre de recette","prix":1500,"categorie":"Livre"}],
  "total": 1500,
  "serial_status": "OK (port COM4)",
  "last_scan": {"uid":"338FE7F7","found":true,"action":"ajoute"}
}
Important : l’API est une API de démonstration sur réseau local. Elle n’a ni authentification ni persistance du panier.
